# 块 3 · 代码切片（把文件切成能审计的小块）

> ⚠️ **只实现本文件里的内容。** 其他块的文件不要动，也不要提前实现（规则见同目录 `README.md`）。
> 做法：从上往下按编号执行，每完成一步就对照「验收」打勾；验收不过就查「卡住怎么办」。


> **目标**：给 `CodeParseService` 一个文件路径和语言，返回一组 `CodeChunk`，每块的 `startLine/endLine` 与源码**逐行对齐**。
> **前置**：块 1 完成（有 javaparser 依赖）。块 2 未完成也能做，但建议先做块 2。
> **产出**：3 个文件（1 个实体、1 个 service、1 个 python 脚本）+ 一个临时测试接口。
> **估时**：1 天。
> **验收标准**：随便挑 3 个块，去 IDEA 里看第 `startLine` 行，**必须正好是**这块代码的第一行（含注解、签名）。

---

## 1. 这一步在回答什么问题

"我能把一整棵代码树，换成模型看得懂的、有坐标的小段吗？"

模型一次吃不下几千行，就算吃得下也会漏。所以要切成"函数级"的小块。
但切片最难的不是切，是**行号不能错**——后面所有报告都要靠 `startLine` 定位到人看的代码，
错一行，报告就指到别处，评审时是致命的。

所以这一块的验收不是"能切出块"，而是"**行号对得上**"。

import lombok.AllArgsConstructor;
import lombok.Data;
import lombok.NoArgsConstructor;

import java.util.List;

@Data
@NoArgsConstructor
@AllArgsConstructor
public class CodeChunk {

    /** 相对或绝对路径，用于报告展示 */
    private String filePath;

    /** java / python */
    private String language;

    /** 方法名 / 类名 / 函数名 */
    private String nodeName;

    /** method / class / window（超长方法被切成了窗口） */
    private String kind;

    /** 1-based，含 */
    private Integer startLine;

    /** 1-based，含 */
    private Integer endLine;

    /** 这段的源码 */
    private String code;

    /** 切分时顺带命中的关键词线索，如 sql、exec、password，供后续挑规则用 */

}

### 3.2 `service/CodeParseService.java`

```java
package com.audit.service;

import com.audit.model.CodeChunk;
import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.github.javaparser.StaticJavaParser;
import com.github.javaparser.ast.CompilationUnit;
import com.github.javaparser.ast.body.ClassDeclaration;
import com.github.javaparser.ast.body.MethodDeclaration;
import com.github.javaparser.ast.Node;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.core.io.ClassPathResource;
import org.springframework.stereotype.Service;

import java.io.File;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.*;
import java.util.stream.Collectors;

@Slf4j
@Service
@RequiredArgsConstructor
public class CodeParseService {

    /** 单块超过这个行数就再拆窗口，模型一次别超过 80 行 */
    private static final int MAX_CHUNK_LINES = 80;

    private final ObjectMapper objectMapper;

    public List<CodeChunk> parse(String filePath, String language) throws Exception {
        List<String> allLines = Files.readAllLines(Path.of(filePath), StandardCharsets.UTF_8);
        List<CodeChunk> chunks = "python".equalsIgnoreCase(language)
                ? parsePython(filePath, allLines)
                : parseJava(filePath, allLines);
        log.info("切片完成：{} 行 → {} 块", allLines.size(), chunks.size());
        return chunks;
    }

    // ---------- Java ----------

    private List<CodeChunk> parseJava(String filePath, List<String> allLines) throws Exception {
        CompilationUnit cu = StaticJavaParser.parse(new File(filePath));
        List<CodeChunk> chunks = new ArrayList<>();

        // 方法优先：方法块比类块更有信息量
        for (MethodDeclaration m : cu.findAll(MethodDeclaration.class)) {
            chunks.addAll(toChunks(allLines, filePath, "java", m.getNameAsString(), "method", m));
        }
        // 没有方法的类（如纯字段类）也要留一块，否则整个文件被跳过
        for (ClassDeclaration c : cu.findAll(ClassDeclaration.class)) {
            boolean hasMethod = !c.getMethods().isEmpty();
            if (!hasMethod) {
                chunks.addAll(toChunks(allLines, filePath, "java", c.getNameAsString(), "class", c));
            }
        }
        return chunks;
    }

    private List<CodeChunk> toChunks(List<String> allLines, String filePath, String language,
                                     String nodeName, String kind, Node node) {
        int begin = node.getBegin().map(p -> p.line).orElse(0);
        int end = node.getEnd().map(p -> p.line).orElse(0);
        if (begin <= 0 || end < begin) return List.of();

        List<CodeChunk> result = new ArrayList<>();
        int cursor = begin;
        while (cursor <= end) {
            int windowEnd = Math.min(cursor + MAX_CHUNK_LINES - 1, end);
            result.add(build(allLines, filePath, language, nodeName,
                    cursor == begin ? kind : "window", cursor, windowEnd));
            cursor = windowEnd + 1;
        }
        return result;
    }

    // ---------- Python ----------

    private List<CodeChunk> parsePython(String filePath, List<String> allLines) throws Exception {
        Path script = new ClassPathResource("python/parse_python.py").getFile().toPath();
        ProcessBuilder pb = new ProcessBuilder("python", script.toString(), filePath);
        pb.redirectErrorStream(false);
        pb.environment().put("PYTHONIOENCODING", "utf-8");

        Process proc = pb.start();
        String out = new String(proc.getInputStream().readAllBytes(), StandardCharsets.UTF_8);
        String err = new String(proc.getErrorStream().readAllBytes(), StandardCharsets.UTF_8);
        int code = proc.waitFor();
        if (code != 0) {
            throw new IllegalStateException("Python 解析失败：" + err);
        }

        List<Map<String, Object>> nodes = objectMapper.readValue(out, new TypeReference<>() {});
        List<CodeChunk> chunks = new ArrayList<>();
        for (Map<String, Object> n : nodes) {
            int begin = ((Number) n.get("startLine")).intValue();
            int end = ((Number) n.get("endLine")).intValue();
            String name = String.valueOf(n.get("nodeName"));
            String kind = String.valueOf(n.get("kind"));
            int cursor = begin;
            while (cursor <= end) {
                int windowEnd = Math.min(cursor + MAX_CHUNK_LINES - 1, end);
                chunks.add(build(allLines, filePath, "python", name,
                        cursor == begin ? kind : "window", cursor, windowEnd));
                cursor = windowEnd + 1;
            }
        }
        return chunks;
    }

    // ---------- 公共 ----------

    private CodeChunk build(List<String> allLines, String filePath, String language,
                            String nodeName, String kind, int start, int end) {
        // allLines 是 0-based，行号是 1-based：所以第 start 行是 allLines.get(start - 1)
        String code = String.join("\n",
                allLines.subList(start - 1, Math.min(end, allLines.size())));
        return new CodeChunk(filePath, language, nodeName, kind, start, end,
                code, detectHints(code));
    }

    private List<String> detectHints(String code) {
        String lower = code.toLowerCase();
        Map<String, String[]> hintMap = new LinkedHashMap<>();
        hintMap.put("sql", new String[]{"select ", "insert ", "update ", "delete ", "executequer"});
        hintMap.put("exec", new String[]{"runtime.getruntime", "exec(", "subprocess", "os.system", "eval("});
        hintMap.put("crypto", new String[]{"md5", "sha1", "des", "ecb", "math.random", "random."});
        hintMap.put("path", new String[]{"../", "new file(", "open(", "path.of", "getparamet"});
        hintMap.put("log", new String[]{"log.info", "print(", "system.out"});
        hintMap.put("auth", new String[]{"session", "cookie", "jwt", "password", "token"});

        return hintMap.entrySet().stream()
                .filter(e -> Arrays.stream(e.getValue()).anyMatch(lower::contains))
                .map(Map.Entry::getKey)
                .collect(Collectors.toList());
    }
}
```

### 3.3 `src/main/resources/python/parse_python.py`

```python
"""用标准库 ast 找出 Python 函数/类的位置，输出 JSON 给 Java 读。

用法：python parse_python.py <file.py>
输出：[{"nodeName": "foo", "kind": "function", "startLine": 12, "endLine": 30}, ...]
"""
import ast
import json
import sys


def collect(tree):
    nodes = []
    for node in ast.walk(tree):
        if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)):
            kind = "method" if is_method(node, tree) else "function"
            nodes.append(make(node, kind))
        elif isinstance(node, ast.ClassDef):
            nodes.append(make(node, "class"))
    nodes.sort(key=lambda n: n["startLine"])
    return nodes


def is_method(node, tree):
    # 简单判断：在 ClassDef 的直接 body 里出现，就当方法
    for parent in ast.walk(tree):
        if isinstance(parent, ast.ClassDef):
            for child in parent.body:
                if child is node:
                    return True
    return False


def make(node, kind):
    return {
        "nodeName": node.name,
        "kind": kind,
        "startLine": node.lineno,
        "endLine": getattr(node, "end_lineno", node.lineno),
    }


def main():
    if len(sys.argv) < 2:
        print("[]")
        return
    with open(sys.argv[1], "r", encoding="utf-8") as f:
        source = f.read()
    tree = ast.parse(source)
    print(json.dumps(collect(tree), ensure_ascii=False))


if __name__ == "__main__":
    main()
```

## 5. 卡住怎么办

| 现象 | 原因 | 修法 |
|---|---|---|
| `Cannot run program "python"` | PATH 里没有 python，或 IDEA 的环境变量不同 | `python --version` 能出版本即可；不行就把它写成绝对路径 `D:\\python\\python.exe` |
| `Python 解析失败：SyntaxError` | 目标文件是 Python 2 语法 / 用了新语法 | 换文件；或 `ast.parse` 前先 `tokenize.open` |
| 块的行号整体偏 1 | 忘了 1-based | 检查 `subList(start - 1, ...)` |
| `endLine` 是 0 | 老版本 ast 缺 `end_lineno` | 代码里已用 `getattr` 兜底；Python 需 ≥3.8 |
| 中文乱码 | 子进程输出编码 | 代码里已设 `PYTHONIOENCODING=utf-8` |
| 块数特别多 | 只算方法还不够，类里字段被切 | 正常；块 5 会按 `categoryHints` 过滤 |
