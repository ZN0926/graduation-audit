> ⚠️ **只实现本文件里的内容。** 其他块的文件不要动，也不要提前实现（规则见同目录 `README.md`）。

> **目标**：审计结束后自动生成一份 Markdown 报告（合规率 + 违规清单 + 修复建议），能通过接口取回；前端能跨域调；异常有统一返回。
> **前置**：块 5 完成（`finding` 表里有数据）。
> **产出**：`ReportService`、`ReportController`、`WebConfig`、`GlobalExceptionHandler`，共 4 个文件。
> **估时**：1 天。
> **验收标准**：上传 → 拿到 taskId → 取报告 → 报告里合规率与 finding 数量**互相算得通**。

## 1. 这一步在回答什么问题

"用户凭什么相信这个系统？"

一堆 JSON 没人看。要的是：**这份代码什么水平（合规率）、哪几处有问题（定位）、怎么改（建议）**。
而且合规率必须能用手算出来核对——如果算不对，答辩时被问一句就崩了。

## 3. 操作步骤

### 3.1 `service/ReportService.java`

```java
package com.audit.service;

import com.audit.model.*;
import com.audit.repository.*;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.*;
import java.util.stream.Collectors;

@Slf4j
@Service
@RequiredArgsConstructor
public class ReportService {

    private final AuditTaskRepository taskRepository;
    private final FindingRepository findingRepository;
    private final RuleRepository ruleRepository;
    private final ReportRepository reportRepository;

    @Transactional
    public Report generate(Long taskId) {
        AuditTask task = taskRepository.findById(taskId).orElseThrow();
        List<Finding> findings = findingRepository.findByTaskIdAndViolated(taskId, true);
        long ruleCount = ruleRepository.countByLanguage(task.getLanguage());

        // 合规率 = 1 - 命中的不同规则数 / 该语言规则总数
        long hitRules = findings.stream().map(Finding::getRuleId).distinct().count();
        double rate = ruleCount == 0 ? 1.0 : 1.0 - ((double) hitRules / ruleCount);
        rate = Math.max(0, Math.min(1, rate));

        String markdown = buildMarkdown(task, findings, ruleCount, hitRules, rate);

        Report report = reportRepository.findByTaskId(taskId).orElseGet(Report::new);
        report.setTaskId(taskId);
        report.setComplianceRate(rate);
        report.setSummaryText("共命中 " + findings.size() + " 处，涉及 " + hitRules
                + " 类规则，合规率 " + String.format("%.1f%%", rate * 100));
        report.setMarkdown(markdown);
        report.setHtml(toHtml(markdown));
        return reportRepository.save(report);
    }

    public Report get(Long taskId) {
        return reportRepository.findByTaskId(taskId).orElseGet(() -> generate(taskId));
    }

    private String buildMarkdown(AuditTask task, List<Finding> findings,
                                 long ruleCount, long hitRules, double rate) {
        StringBuilder sb = new StringBuilder();
        sb.append("# 代码审计报告\n\n");
        sb.append("| 项 | 值 |\n|---|---|\n");
        sb.append("| 文件 | ").append(task.getFileName()).append(" |\n");
        sb.append("| 语言 | ").append(task.getLanguage()).append(" |\n");
        sb.append("| 规则版本 | ").append(task.getRuleVersion()).append(" |\n");
        sb.append("| 代码块数 | ").append(task.getTotalChunks()).append(" |\n");
        sb.append("| 规则总数 | ").append(ruleCount).append(" |\n");
        sb.append("| 命中规则数 | ").append(hitRules).append(" |\n");
        sb.append("| 违规条数 | ").append(findings.size()).append(" |\n");
        sb.append("| 合规率 | ").append(String.format("%.1f%%", rate * 100)).append(" |\n\n");

        if (findings.isEmpty()) {
            sb.append("未发现违规。\n");
            return sb.toString();
        }

        sb.append("## 违规清单\n\n");
        // 按严重程度排：HIGH 在前
        Map<String, Integer> order = Map.of("HIGH", 0, "MEDIUM", 1, "LOW", 2);
        findings.sort(Comparator.comparingInt(f -> order.getOrDefault(f.getSeverity(), 3)));

        int i = 1;
        for (Finding f : findings) {
            sb.append("### ").append(i++).append(". ").append(f.getRuleId())
                    .append("（").append(f.getSeverity()).append("）\n\n");
            sb.append("**位置**：`").append(f.getFilePath()).append("` 第 ")
                    .append(f.getStartLine());
            if (!Objects.equals(f.getStartLine(), f.getEndLine())) {
                sb.append("-").append(f.getEndLine());
            }
            sb.append(" 行\n\n");
            sb.append("**原因**：").append(f.getReason()).append("\n\n");
            sb.append("**修复建议**：").append(f.getFixSuggestion()).append("\n\n");
            sb.append("**置信度**：").append(f.getConfidence()).append("\n\n");
        }
        return sb.toString();
    }

    /** 极简 HTML：够前端 iframe 预览即可 */
    private String toHtml(String markdown) {
        String body = Arrays.stream(markdown.split("\n"))
                .map(line -> {
                    if (line.startsWith("### ")) return "<h3>" + esc(line.substring(4)) + "</h3>";
                    if (line.startsWith("## ")) return "<h2>" + esc(line.substring(3)) + "</h2>";
                    if (line.startsWith("# ")) return "<h1>" + esc(line.substring(2)) + "</h1>";
                    if (line.isBlank()) return "";
                    return "<p>" + esc(line) + "</p>";
                })
                .collect(Collectors.joining("\n"));
        return "<!doctype html><meta charset=\"utf-8\"><body>" + body + "</body>";
    }

    private String esc(String s) {
        return s.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;");
    }
}
```

> 合规率的定义要写进论文：**1 − 命中规则数 / 规则总数**。
> 不要用"1 − 违规行数 / 总行数"——行数受代码风格影响，没法横向比较。

### 3.2 `controller/ReportController.java`

```java
package com.audit.controller;

import com.audit.model.Report;
import com.audit.service.ReportService;
import lombok.RequiredArgsConstructor;
import org.springframework.http.MediaType;
import org.springframework.web.bind.annotation.*;

import java.util.LinkedHashMap;
import java.util.Map;

@RestController
@RequestMapping("/api/reports")
@RequiredArgsConstructor
public class ReportController {

    private final ReportService reportService;

    @GetMapping("/{taskId}")
    public Map<String, Object> json(@PathVariable Long taskId) {
        Report r = reportService.get(taskId);
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("taskId", r.getTaskId());
        m.put("complianceRate", r.getComplianceRate());
        m.put("summary", r.getSummaryText());
        m.put("markdown", r.getMarkdown());
        return m;
    }

    @GetMapping(value = "/{taskId}/markdown", produces = "text/markdown;charset=utf-8")
    public String markdown(@PathVariable Long taskId) {
        return reportService.get(taskId).getMarkdown();
    }

    @GetMapping(value = "/{taskId}/html", produces = MediaType.TEXT_HTML_VALUE)
    public String html(@PathVariable Long taskId) {
        return reportService.get(taskId).getHtml();
    }
}
```

### 3.3 `config/WebConfig.java`

```java
package com.audit.config;

import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.CorsRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
public class WebConfig implements WebMvcConfigurer {

    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOriginPatterns("*")
                .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
                .allowedHeaders("*")
                .allowCredentials(true)
                .maxAge(3600);
    }
}
```

> `allowedOrigins("*")` 和 `allowCredentials(true)` 不能同时用，会抛异常；
> 必须用 `allowedOriginPatterns`。这是配 CORS 最常踩的一个坑。

### 3.4 `config/GlobalExceptionHandler.java`

```java
package com.audit.config;

import lombok.extern.slf4j.Slf4j;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.time.LocalDateTime;
import java.util.Map;

@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(IllegalArgumentException.class)
    public ResponseEntity<Map<String, Object>> badRequest(IllegalArgumentException e) {
        return ResponseEntity.badRequest().body(body(400, e.getMessage()));
    }

    @ExceptionHandler(Exception.class)
    public ResponseEntity<Map<String, Object>> any(Exception e) {
        log.error("未处理异常", e);
        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR)
                .body(body(500, e.getMessage()));
    }

    private Map<String, Object> body(int code, String message) {
        return Map.of("code", code,
                "message", message == null ? "unknown" : message,
                "time", LocalDateTime.now().toString());
    }
}
```

## 5. 卡住怎么办

| 现象 | 原因 | 修法 |
|---|---|---|
| `When allowCredentials is true, allowedOrigins cannot contain "*"` | 用了 `allowedOrigins` | 换成 `allowedOriginPatterns`（代码里已是） |
| 前端 `CORS error` 但 curl 正常 | 预检没通过 | 先跑上面第 8 条，看 OPTIONS 是否 200 |
| `get()` 每次重新生成报告 | 没落库 / 事务没提交 | `generate` 上有 `@Transactional`，检查是否真的 save 了 |
| 合规率是负数 | 命中规则数 > 规则总数 | 说明有 finding 的 ruleId 是编的；检查块 5 的 `allowed` 过滤 |
| Markdown 里挤成一行 | 前端没渲染 | 后端换行是 `\n`，前端用 `marked` 或 `<pre>` 都行 |
| 报告里中文问号 | 响应头没带 charset | `produces` 里已带 `charset=utf-8` |
