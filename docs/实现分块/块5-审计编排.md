# 块 5 · 审计编排（一次上传跑完全程）

> ⚠️ **只实现本文件里的内容。** 其他块的文件不要动，也不要提前实现（规则见同目录 `README.md`）。
> 做法：从上往下按编号执行，每完成一步就对照「验收」打勾；验收不过就查「卡住怎么办」。


> **目标**：`POST /api/audit` 上传一个 Java/Python 文件，系统自动切片、按块挑规则、调模型判定、把违规存进 `finding` 表，返回 `taskId`。
> **前置**：块 3（切片）＋ 块 4（规则库里有 ≥20 条规则）。
> **产出**：2 个 controller、1 个 service、2 个提示词方法。
> **估时**：2 天。
> **验收标准**：上传一个**故意写坏**的 demo 文件，`finding` 表里出现至少 1 条违规，且 `start_line` 指到那行坏代码。

---

## 1. 这一步在回答什么问题

"把切片和规则拼起来，能不能稳定地判出违规，而且判的理由能对上代码？"

这里最容易翻车的是**幻觉**：模型会编一个不存在的行号、引用一条你没给它的规则、或者把安全代码判成违规。
所以这一块的重点不是"能判出漏洞"，而是**"判出来的每一条都能被验证"**。

三道闸：
1. **只给相关的规则**（按 `categoryHints` 路由），模型没见过的规则不会凭空引用；
2. **只给它一块代码**，行号以块为边界，超出范围直接丢弃；
3. **`ruleId` 必须在给出的规则里**，不在就丢。

```java
public static final String AUDIT_SYSTEM = """
        你是代码安全审计引擎。你的判定必须严格基于给出的规则与代码。
        硬性约束：
        1. 只输出 JSON 对象，不要 markdown 围栏、不要解释。
        2. 只能引用【规则清单】里出现过的 ruleId；不得编造规则。
        3. 只能使用【代码】里真实存在的行号；startLine/endLine 必须落在给定区间内。
        4. 逐条判定每条规则：violated=true 表示该代码违反了这条规则。
        5. reason 必须指出具体证据（哪个 API、哪个参数、哪一行），不要写"存在风险"这类空话。
        6. fix_suggestion 给出可直接照做的改法，最多两句。
        7. confidence 取 0~1：证据明确给 0.8 以上；需要推断场景给 0.5~0.7；
           拿不准给 0.4 以下，并在 reason 里注明"待人工确认"。
        输出格式：
        {"violations":[{"ruleId":"...","violated":true,"severity":"HIGH",
        "startLine":12,"endLine":14,"reason":"...","fixSuggestion":"...","confidence":0.85}],
        "summary":"一句话概括这个代码片段的整体风险"}
        """;

            %s

            ```

### 3.2 `util/FileUtil.java`

package com.audit.util;

import java.nio.file.Files;
import java.nio.file.Path;

public final class FileUtil {

    private FileUtil() {
    }

    public static String detectLanguage(String fileName) {
        String lower = fileName.toLowerCase();
        if (lower.endsWith(".java")) return "java";
        if (lower.endsWith(".py")) return "python";
        throw new IllegalArgumentException("只支持 .java 和 .py：" + fileName);
    }

    public static Path save(Path dir, String fileName, byte[] bytes) throws Exception {
        Files.createDirectories(dir);
        // 去掉路径分隔符，防止 ../ 穿越
        String safe = fileName.replaceAll("[\\\\/:*?\"<>|]", "_");
        Path target = dir.resolve(System.currentTimeMillis() + "_" + safe);
        Files.write(target, bytes);
        return target;
    }
}

### 3.3 `service/AuditService.java`

```java
package com.audit.service;

import com.audit.model.*;
import com.audit.prompt.PromptTemplates;
import com.audit.repository.*;
import com.audit.util.JsonUtil;
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.*;
import java.util.stream.Collectors;

@Slf4j
@Service
@RequiredArgsConstructor
public class AuditService {

    /** 单次送给模型的规则上限，控制 token */
    private static final int MAX_RULES_PER_CHUNK = 15;

    private final CodeParseService codeParseService;
    private final LlmService llmService;
    private final RuleRepository ruleRepository;
    private final AuditTaskRepository taskRepository;
    private final FindingRepository findingRepository;
    private final ObjectMapper objectMapper;

    @Transactional
    public Long createTask(String fileName, String language) {
        AuditTask task = new AuditTask();
        task.setFileName(fileName);
        task.setLanguage(language);
        task.setStatus("PENDING");
        return taskRepository.save(task).getId();
    }

    public void runAudit(Long taskId, String filePath) {
        AuditTask task = taskRepository.findById(taskId).orElseThrow();
        try {
            task.setStatus("RUNNING");
            taskRepository.save(task);

            List<CodeChunk> chunks = codeParseService.parse(filePath, task.getLanguage());
            List<Rule> rules = ruleRepository.findByLanguage(task.getLanguage());
            if (rules.isEmpty()) {
                throw new IllegalStateException("规则库为空，先执行块 4 的蒸馏");
            }
            task.setTotalChunks(chunks.size());
            task.setRuleVersion("rules-" + rules.size());
            taskRepository.save(task);

            for (CodeChunk chunk : chunks) {
                List<Rule> picked = pickRules(rules, chunk);
                if (picked.isEmpty()) {
                    task.setDoneChunks(task.getDoneChunks() + 1);
                    continue;
                }
                try {
                    judge(task, filePath, chunk, picked);
                } catch (Exception e) {
                    log.error("块判定失败 task={} {}-{}：{}", taskId,
                            chunk.getStartLine(), chunk.getEndLine(), e.getMessage());
                }
                task.setDoneChunks(task.getDoneChunks() + 1);
                taskRepository.save(task);
            }

            task.setStatus("DONE");
            task.setFinishedAt(java.time.LocalDateTime.now());
        } catch (Exception e) {
            task.setStatus("FAILED");
            task.setErrorMsg(e.getMessage());
            log.error("审计失败 task={}", taskId, e);
        }
        taskRepository.save(task);
    }

    private void judge(AuditTask task, String filePath, CodeChunk chunk, List<Rule> rules) throws Exception {
        String rulesJson = objectMapper.writeValueAsString(
                rules.stream().map(this::brief).collect(Collectors.toList()));

        String raw = llmService.chatForObject(
                PromptTemplates.AUDIT_SYSTEM,
                PromptTemplates.auditUser(task.getLanguage(), filePath,
                        chunk.getStartLine(), chunk.getEndLine(), chunk.getCode(), rulesJson));

        JsonNode root = objectMapper.readTree(JsonUtil.stripFence(raw));
        JsonNode violations = root.path("violations");
        if (!violations.isArray()) return;

        Set<String> allowed = rules.stream().map(Rule::getRuleId).collect(Collectors.toSet());

        for (JsonNode v : violations) {
            if (!v.path("violated").asBoolean(false)) continue;

            String ruleId = v.path("ruleId").asText();
            if (!allowed.contains(ruleId)) {
                log.warn("丢弃：规则 {} 不在本次清单内", ruleId);
                continue;
            }
            int start = v.path("startLine").asInt(chunk.getStartLine());
            int end = v.path("endLine").asInt(start);
            if (start < chunk.getStartLine() || end > chunk.getEndLine() || end < start) {
                log.warn("丢弃：行号越界 {} {}-{}（区间 {}-{}）", ruleId, start, end,
                        chunk.getStartLine(), chunk.getEndLine());
                continue;
            }

            Finding f = new Finding();
            f.setTaskId(task.getId());
            f.setRuleId(ruleId);
            f.setFilePath(filePath);
            f.setStartLine(start);
            f.setEndLine(end);
            f.setCodeSnippet(chunk.getCode());
            f.setViolated(true);
            f.setSeverity(v.path("severity").asText("MEDIUM"));
            f.setReason(v.path("reason").asText());
            f.setFixSuggestion(v.path("fixSuggestion").asText());
            f.setConfidence(Math.min(1.0, Math.max(0.0, v.path("confidence").asDouble(0.5))));
            findingRepository.save(f);
        }
    }

    /** 按线索挑规则；线索为空就全给（有上限） */
    private List<Rule> pickRules(List<Rule> all, CodeChunk chunk) {
        List<String> hints = chunk.getCategoryHints();
        List<Rule> picked;
        if (hints == null || hints.isEmpty()) {
            picked = all;
        } else {
            Set<String> upper = hints.stream().map(String::toUpperCase).collect(Collectors.toSet());
            picked = all.stream()
                    .filter(r -> r.getCategory() != null && upper.contains(r.getCategory().toUpperCase()))
                    .collect(Collectors.toList());
            if (picked.isEmpty()) picked = all;
        }
        return picked.size() > MAX_RULES_PER_CHUNK
                ? picked.subList(0, MAX_RULES_PER_CHUNK)
                : picked;
    }

    /** 送给模型的规则只保留判定必需字段，省 token */
    private Map<String, Object> brief(Rule r) {
        Map<String, Object> m = new LinkedHashMap<>();
        m.put("ruleId", r.getRuleId());
        m.put("category", r.getCategory());
        m.put("title", r.getTitle());
        m.put("severity", r.getSeverity());
        m.put("detectionHint", r.getDetectionHint());
        m.put("negativeExample", r.getNegativeExample());
        return m;
    }
}
```

### 3.4 `controller/UploadController.java`

```java
package com.audit.controller;

import com.audit.service.AuditService;
import com.audit.util.FileUtil;
import lombok.RequiredArgsConstructor;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;

import java.nio.file.Path;
import java.util.Map;

@RestController
@RequestMapping("/api/upload")
@RequiredArgsConstructor
public class UploadController {

    private final AuditService auditService;

    @Value("${audit.upload-dir:uploads}")
    private String uploadDir;

    @PostMapping
    public Map<String, Object> upload(@RequestParam("file") MultipartFile file) throws Exception {
        String fileName = file.getOriginalFilename() == null ? "unknown" : file.getOriginalFilename();
        String language = FileUtil.detectLanguage(fileName);
        Path saved = FileUtil.save(Path.of(uploadDir), fileName, file.getBytes());

        Long taskId = auditService.createTask(fileName, language);
        auditService.runAudit(taskId, saved.toString());
        return Map.of("taskId", taskId, "language", language, "savedAs", saved.getFileName().toString());
    }
}
```

> 现在是**同步**执行：接口会等到整份文件判完才返回。文件小的时候没问题；
> 想做成"提交后立刻返回、前端轮询进度"，把 `runAudit` 丢进 `@Async` 线程池即可，其它不用改。

### 3.5 `controller/AuditController.java`

```java
package com.audit.controller;

import com.audit.model.AuditTask;
import com.audit.model.Finding;
import com.audit.repository.AuditTaskRepository;
import com.audit.repository.FindingRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/audit")
@RequiredArgsConstructor
public class AuditController {

    private final AuditTaskRepository taskRepository;
    private final FindingRepository findingRepository;

    @GetMapping("/tasks")
    public List<AuditTask> tasks() {
        return taskRepository.findAllByOrderByIdDesc();
    }

    @GetMapping("/tasks/{id}")
    public AuditTask task(@PathVariable Long id) {
        return taskRepository.findById(id).orElseThrow();
    }

    @GetMapping("/tasks/{id}/findings")
    public List<Finding> findings(@PathVariable Long id) {
        return findingRepository.findByTaskIdAndViolated(id, true);
    }
}
```

## 5. 卡住怎么办

| 现象 | 原因 | 修法 |
|---|---|---|
| 一条 finding 都没有 | 规则库为空 / 提示词没让它判 | 先 `GET /api/rules` 确认有规则；再把 `AUDIT_SYSTEM` 里"逐条判定"加粗强调 |
| finding 全被丢弃，日志 `行号越界` | 模型按整个文件的行号算 | 提示词里已给区间；仍不行就在 prompt 里明确"行号必须相对于给定区间，且在该区间内" |
| 全被丢弃，日志 `不在本次清单内` | 模型引用了别的规则 | 正常拦截；若太多，把 `brief()` 里的 `category` 也删掉，减少干扰 |
| `task` 一直 `RUNNING` | 同步执行被前端超时掐断 | 换 `@Async`，或先只传小文件 |
| 判定太慢（>2 分钟） | 块多 × 规则多 | 降 `MAX_RULES_PER_CHUNK`，或先把代码用 `categoryHints` 过滤 |
| `status=FAILED`，`errorMsg` 有内容 | 见该字段 | 多半是规则库为空或 python 路径问题 |
| 中文变成 `???` | 上传文件编码 | 前端按 UTF-8 读，后端 `Files.write` 已是字节级，一般不会；检查控制台编码 |
