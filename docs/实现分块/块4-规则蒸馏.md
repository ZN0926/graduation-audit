# 块 4 · 规则蒸馏（系统的核心卖点）

> ⚠️ **只实现本文件里的内容。** 其他块的文件不要动，也不要提前实现（规则见同目录 `README.md`）。
> 做法：从上往下按编号执行，每完成一步就对照「验收」打勾；验收不过就查「卡住怎么办」。


> **目标**：`POST /api/rules/distill?language=java` 跑一次，从 `examples/` 里的优质代码蒸馏出 **≥20 条**结构化规则，存进 `rule` 表，`GET /api/rules?language=java` 能查出来。
> **前置**：块 1（表）＋ 块 2（模型能调通）。
> **产出**：1 个提示词类、1 个 service、1 个 controller，加 4~6 个范例文件。
> **估时**：1.5 ~ 2 天（含调提示词）。
> **验收标准**：规则条数 ≥20，且抽 3 条检查"`detection_hint` 能不能直接照着找代码"。**不能，就是提示词没写对，回去改。**

---

## 1. 这一步在回答什么问题

"我能不能让模型把『安全知识』变成『可复用的检查项』，而不是每次审计都临场发挥？"

这是整篇论文的创新点。差别在这里：

| 做法 | 后果 |
|---|---|
| 每次把代码丢给模型问"有没有漏洞" | 每次答案不一样、没法解释、没法复用、答辩问"你的规则哪来的"答不上 |
| 先产出一套**固定的规则集**，再拿规则去判代码 | 规则可展示、可版本化、可评测、可人工修订 |

所以这一块不是"再调一次模型"，而是**产出一个资产**。产出的规则集就是论文里那张表。

## 3. 操作步骤

### 3.1 准备范例（原料质量决定规则质量）

在 `src/main/resources/examples/java/` 放 **4~6 个真实风格**的 Java 文件，覆盖这几类场景，每个 40~120 行：

| 文件建议 | 要包含的写法 |
|---|---|
| `JdbcDemo.java` | 字符串拼接 SQL（坏）+ `PreparedStatement`（好）；`Statement.execute` |
| `FileDemo.java` | `new File(userInput)`、`../` 拼接（坏）+ 路径规范化（好） |
| `CryptoDemo.java` | `MD5`、`DES/ECB`、`Math.random()` 生成 token（坏）+ `SecureRandom`、`AES/GCM`（好） |
| `AuthDemo.java` | 明文密码比较、session 固定（坏）+ BCrypt、登录后重建 session（好） |
| `LogDemo.java` | 把密码/token 打进日志（坏）+ 脱敏（好） |

Python 侧同理 3~4 个：`sql_demo.py`（`execute("...%s" % x)` vs 参数化）、`pickle_demo.py`（`pickle.loads` / `eval`）、`path_demo.py`（`open(user_input)`）、`random_demo.py`（`random.random()` 当 token）。

> 这些文件同时是**论文附录的素材**，写论文时直接引用。

### 3.2 `prompt/PromptTemplates.java`

```java
package com.audit.prompt;

public final class PromptTemplates {

    private PromptTemplates() {
    }

    public static final String DISTILL_SYSTEM = """
            你是资深代码安全审计专家，熟悉 CWE 与 OWASP Top 10。
            任务：从给定的示例代码中，归纳出可复用的安全编码检查规则。

            要求：
            1. 只输出 JSON 数组，不要任何解释文字、不要 markdown 代码围栏。
            2. 每条规则字段严格如下：
               ruleId, category, cwe, title, description, positiveExample, negativeExample, severity, detectionHint
            3. ruleId 格式为 语言-类别-三位序号，例如 JAVA-SQLI-001、PY-CRYPTO-002。
            4. category 只能取：SQLI, XSS, PATH, CRYPTO, AUTH, DESERIAL, LOG, INPUT。
            5. cwe 写成 CWE-89 这种形式；不确定就给最接近的一个。
            6. severity 只能取：HIGH, MEDIUM, LOW。
            7. detectionHint 必须是"能照着在代码里找"的描述，写清看什么 API、什么参数、
               什么前后关系。禁止写"注意安全""加强校验"这类空话。
            8. positiveExample 是违规写法（正例=命中），negativeExample 是安全写法。
               两个例子的代码各不超过 8 行。
            9. 同一类问题只出一条规则，不要拆分重复。
            """;

    public static String distillUser(String language, String fileName, String code) {
        return """
                语言：%s
                文件：%s
                示例代码：
                ```
                %s
                ```
                请据此归纳规则，输出 JSON 数组。
                """.formatted(language, fileName, code);
    }
}
```

> 第 7 条是整个提示词里最值钱的一句。少了它，模型会给你"应进行输入校验"这种没法执行的话。

### 3.3 `service/RuleDistillService.java`

```java
package com.audit.service;

import com.audit.model.Rule;
import com.audit.prompt.PromptTemplates;
import com.audit.repository.RuleRepository;
import com.audit.util.JsonUtil;
import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.core.io.Resource;
import org.springframework.core.io.support.PathMatchingResourcePatternResolver;
import org.springframework.stereotype.Service;

import java.nio.charset.StandardCharsets;
import java.util.*;

@Slf4j
@Service
@RequiredArgsConstructor
public class RuleDistillService {

    private static final Set<String> SEVERITIES = Set.of("HIGH", "MEDIUM", "LOW");

    private final LlmService llmService;
    private final RuleRepository ruleRepository;
    private final ObjectMapper objectMapper;

    /** 返回值：{新增条数, 跳过条数, 失败文件数} */
    public Map<String, Object> distill(String language) throws Exception {
        List<Resource> files = loadExamples(language);
        if (files.isEmpty()) {
            throw new IllegalStateException("examples/" + language + " 下没有范例文件");
        }

        int inserted = 0, skipped = 0, failed = 0;
        Set<String> batchRuleIds = new HashSet<>();

        for (Resource file : files) {
            String code = new String(file.getInputStream().readAllBytes(), StandardCharsets.UTF_8);
            String fileName = Objects.requireNonNull(file.getFilename());
            try {
                String raw = llmService.chatForArray(
                        PromptTemplates.DISTILL_SYSTEM,
                        PromptTemplates.distillUser(language, fileName, truncate(code, 8000)));

                List<Rule> rules = objectMapper.readValue(raw, new TypeReference<>() {});
                for (Rule r : rules) {
                    if (!isValid(r)) {
                        log.warn("规则字段不合法，丢弃：{}", r.getRuleId());
                        continue;
                    }
                    r.setLanguage(language);
                    if (batchRuleIds.contains(r.getRuleId()) || ruleRepository.existsByRuleId(r.getRuleId())) {
                        skipped++;
                        continue;
                    }
                    batchRuleIds.add(r.getRuleId());
                    ruleRepository.save(r);
                    inserted++;
                }
            } catch (Exception e) {
                failed++;
                log.error("蒸馏失败 {}：{}", fileName, e.getMessage());
            }
        }

        log.info("蒸馏完成 language={} inserted={} skipped={} failed={}", language, inserted, skipped, failed);
        return Map.of("language", language, "inserted", inserted,
                "skipped", skipped, "failed", failed,
                "total", ruleRepository.countByLanguage(language));
    }

    private List<Resource> loadExamples(String language) throws Exception {
        return List.of(new PathMatchingResourcePatternResolver()
                .getResources("classpath*:examples/" + language + "/*"));
    }

    private boolean isValid(Rule r) {
        return notBlank(r.getRuleId())
                && notBlank(r.getTitle())
                && notBlank(r.getDetectionHint())
                && notBlank(r.getSeverity())
                && SEVERITIES.contains(r.getSeverity().toUpperCase())
                && r.getRuleId().length() <= 64;
    }

    private boolean notBlank(String s) {
        return s != null && !s.isBlank();
    }

    private String truncate(String s, int max) {
        return s.length() <= max ? s : s.substring(0, max);
    }
}
```

> `getResources("classpath*:examples/java/*")` 在 jar 包里也能用；
> 用 `classpath:` 单星在打包后会失效，这是常见坑。

### 3.4 `controller/RuleController.java`

```java
package com.audit.controller;

import com.audit.model.Rule;
import com.audit.repository.RuleRepository;
import com.audit.service.RuleDistillService;
import lombok.RequiredArgsConstructor;
import org.springframework.web.bind.annotation.*;

import java.util.List;
import java.util.Map;

@RestController
@RequestMapping("/api/rules")
@RequiredArgsConstructor
public class RuleController {

    private final RuleDistillService ruleDistillService;
    private final RuleRepository ruleRepository;

    @PostMapping("/distill")
    public Map<String, Object> distill(@RequestParam String language) throws Exception {
        return ruleDistillService.distill(language);
    }

    @GetMapping
    public List<Rule> list(@RequestParam(required = false) String language) {
        return language == null ? ruleRepository.findAll() : ruleRepository.findByLanguage(language);
    }

    @DeleteMapping
    public Map<String, Object> clear(@RequestParam String language) {
        long before = ruleRepository.countByLanguage(language);
        ruleRepository.deleteAll(ruleRepository.findByLanguage(language));
        return Map.of("deleted", before);
    }
}
```

## 4. 验收（逐条打勾）

- [ ] `POST http://localhost:8080/api/rules/distill?language=java` 返回 `inserted ≥ 20`
- [ ] 再调一次，`skipped` 变多、`inserted` 接近 0（幂等，`ruleId` 去重生效）
- [ ] `GET /api/rules?language=java` 能看到全部字段，中文不乱码
- [ ] `SELECT COUNT(*) FROM rule WHERE language='java';` 与接口一致
- [ ] **抽 3 条**看 `detection_hint`：写出"在代码里怎么找"了吗？写出 `Statement.execute` / `Math.random` 这种具体 API 了吗？
- [ ] 有 1 条明显重复的（同类别同意思）→ 说明第 9 条约束生效了；若重复很多，把阈值要求写更死
- [ ] Python 侧也能跑出 ≥15 条

## 5. 卡住怎么办

| 现象 | 原因 | 修法 |
|---|---|---|
| `inserted=0`，日志 `蒸馏失败` | 返回不是纯 JSON | 用 `chatForArray`（已经抠过 `[]`）；再不行打印原始返回看前面是不是有解释文字 |
| `detection_hint` 全是空话 | 提示词没约束住 | 把第 7 条再具体化，并在 system 里给一个**正例**："看是否调用了 `Statement.execute` 且参数由 `String` 拼接产生" |
| `ruleId` 撞车很多 | 模型每次都从 001 编 | 库里 `existsByRuleId` 会跳过；想要更多条就换一批范例文件再蒸馏 |
| `examples` 读不到 | 路径写成 `examples/Java/`（大小写）或没进 `target/classes` | 跑一次 `mvn compile` 让资源复制过去 |
| 条数上不去 | 一类问题只出一两条 | 增加范例文件的**场景种类**，而不是增加文件数量 |
| 一次跑太久 | 每个文件一次调用，串行 | 正常，5 个文件约 1~2 分钟；量大再考虑并发 |
