> ⚠️ **只实现本文件里的内容。** 其他块的文件不要动，也不要提前实现（规则见同目录 `README.md`）。

> **目标**：点运行能起来，浏览器能拿到 `/api/ping` 的 `db:connected`，DataGrip 里出现 4 张表。
> **前置**：工程骨架已建好（27 个类，编译通过），MySQL 服务已启动，`audit_db` 与账号 `audit` 已建。
> **产出**：8 个文件写完 + 4 张表。

> **验收标准**：`/api/ping` 返回 `"db":"connected"` 且 `SHOW TABLES` 有 4 张表。**不达标别往下走。**

---

## 1. 这一步在回答什么问题

"我的代码、数据库、配置文件三者对得上吗？"

这三者对不上时，报错长得都一样（`Failed to configure a DataSource` / `Access denied` / 表不存在），
所以先写一个**只有三行逻辑**的接口把链路打通，再去写业务。这样后面任何错误都只可能是业务错误。

## 3. 操作步骤

### 3.1 先让空接口跑起来

把 `PingController.java` 整个替换成：

```java
package com.audit.controller;

import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.time.LocalDateTime;
import java.util.LinkedHashMap;
import java.util.Map;

@RestController
@RequestMapping("/api")
public class PingController {

    private final JdbcTemplate jdbcTemplate;

    public PingController(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    @GetMapping("/ping")
    public Map<String, Object> ping() {
        Map<String, Object> result = new LinkedHashMap<>();
        result.put("status", "ok");
        try {
            Integer one = jdbcTemplate.queryForObject("SELECT 1", Integer.class);
            result.put("db", one != null ? "connected" : "failed");
        } catch (Exception e) {
            result.put("db", "failed");
            result.put("error", e.getClass().getSimpleName() + ": " + e.getMessage());
        }
        result.put("time", LocalDateTime.now().toString());
        return result;
    }
}
```

运行 `GraduationAuditApplication`，看到 `Started GraduationAuditApplication in x seconds` 后访问：

```
http://localhost:8080/api/ping
```

期望：`{"status":"ok","db":"connected","time":"..."}`。**这一步过了再往下。**

package com.audit.model;

import jakarta.persistence.*;
import lombok.Data;

import java.time.LocalDateTime;

@Data
@Entity
@Table(name = "rule", indexes = {
        @Index(name = "idx_rule_language", columnList = "language"),
        @Index(name = "idx_rule_category", columnList = "category")

public class Rule {

    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "rule_id", nullable = false, unique = true, length = 64)
    private String ruleId;

    @Column(nullable = false, length = 16)
    private String language;

    @Column(length = 64)
    private String category;

    @Column(length = 32)
    private String cwe;

    @Column(nullable = false, length = 200)
    private String title;

    @Column(columnDefinition = "TEXT")
    private String description;

    @Column(name = "positive_example", columnDefinition = "TEXT")
    private String positiveExample;

    @Column(name = "negative_example", columnDefinition = "TEXT")
    private String negativeExample;

    @Column(length = 16)
    private String severity;

    @Column(name = "detection_hint", columnDefinition = "TEXT")
    private String detectionHint;

    @Column(name = "evidence_quote", length = 200)
    private String evidenceQuote;

    @Column(name = "created_at")
    private LocalDateTime createdAt = LocalDateTime.now();
}

## 5. 卡住怎么办

| 现象 | 原因 | 修法 |
|---|---|---|
| `Failed to configure a DataSource` | yaml 里 `spring.datasource` 缩进错 / 不存在 | 它必须是 `spring:` 的子节点，缩进两格 |
| `Access denied for user 'audit'` | MySQL 服务没启动 | `net start MySQL80`（这个是手动启动类型） |
| `Unknown database 'audit_db'` | 库不存在 | DataGrip 里 `CREATE DATABASE audit_db` |
| 满屏红色、`getName()` 找不到 | Lombok 注解处理器没开 | `设置 → 构建、执行、部署 → 编译器 → 注解处理器` 勾上 |
| `Table 'audit_db.rule' doesn't exist` 但启动没报错 | 实体没被扫描 | 实体必须在 `com.audit` 或其子包 |
| `Port 8080 was already in use` | 旧进程没关 | IDEA 停止，或 yaml 里换端口 |
